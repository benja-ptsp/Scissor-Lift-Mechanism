# parts (v3)

One file per part in `STEP/` and `STL/` (units mm; choose "millimeter" when importing STL).
All parts are saved in assembly coordinates — open them together and they line up.

| No | Part |
|---|---|
| 01 | TopPlate |
| 02 | BasePlate |
| 03 | LowerArm_Left (3 built-in pins) |
| 04 | LowerArm_Right (3 built-in pins) |
| 05 | UpperArms_with_Pins_and_TopSlideRod |
| 06 | UpperLinks_with_TopPivotRod |
| 07 | LowerLinks_with_BottomSlideRod |

Parts 05–07 have pins/rods fused in and cannot be assembled after printing separately — print the full set with the `.3mf` in `../assembly/`.
